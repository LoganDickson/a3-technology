# Objective

Update all Windows devices to Windows 11. Must be completed BEFORE Summer!

## Why It's Necessary

> [!WARNING]Microsoft has officially announced that support for Windows 10 will end on October 14, 2025. After this date, Windows 10 will no longer receive security updates, patches, or technical support, even for critical vulnerabilities.

To ensure our school district maintains a secure and reliable digital learning environment, it is essential that we transition all eligible devices to Windows 11. This upgrade will help us:

🔒 **Maintain system security** – Windows 11 receives regular security patches that protect against modern threats.

✅ **Stay compliant** – Many software vendors and educational platforms will eventually drop support for Windows 10.

🛠️ **Ensure IT supportability** – Future hardware and software support will focus on Windows 11 compatibility.

This is a proactive step to protect student and staff data, improve performance across district devices, and avoid disruption due to unsupported technology.


### 🛠️ Plan of Action 

To ensure a secure, efficient, and minimally disruptive transition to Windows 11 across the district, we’ve outlined the following multi-phase plan:

---

#### 💾 **1. Data Backup & User Preparation**

- Notify staff about scheduled upgrade windows.
    
- Encourage **user data backup** to Google Drive.
    
- Provide FAQ and support docs on what to expect before and after the upgrade.
    

---

#### 💻 **2. Testing**
   
- Test image on a sample set of devices across different models and user roles (teachers, admin, labs).

- Determine  the how long each device takes to upgrade and how many can be done at one time by one person.


---

#### 🗓️ **3. Upgrade Rollout Schedule**

- Coordinate with **school site admins** to build an upgrade calendar.
    
- Schedule rollouts in **batches** to allow for troubleshooting and minimal downtime.
    

---

#### 🧰 **4. Upgrade Execution**

- Deploy upgrades using one or more of the following methods:
    
    - In-place upgrade via deployment tools (e.g., SCCM, Intune)
        
    - Manual upgrades for edge cases or older devices
        
    - Full reimage for devices needing clean installs
        
- Verify successful installation and domain rejoin where applicable.
    

---

#### 🔍 **5. Post-Upgrade Validation**

- Confirm functionality of:
    
    - User login and network access
        
    - Printers, shared drives, and essential applications
        
    - Security tools (antivirus, firewall, web filtering)
        
- Check compliance with district IT standards and asset inventory.
    

---

#### 📞 **7. Support & Follow-Up**

- Provide follow-up support for users encountering issues post-upgrade.
    
- Document any upgrade failures or devices that need further attention.
    
- Track completion progress and report to district leadership.
    

---

#### 📚 **8. Communication & Documentation**

- Maintain a **running list of completed upgrades** by site.
    
- Archive documentation for audit and compliance purposes.
